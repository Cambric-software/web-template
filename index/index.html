What you get

Four decisions are already made, so a new site starts at the first product decision instead of at bootstrap.

01

Static by default

Plain HTML, CSS and JavaScript. No framework, no build step required to open it, and no runtime dependency.

02

Local-first

Settings live in this browser, the service worker keeps the shell available offline, and nothing is sent anywhere.

03

Bilingual

English and Arabic, including right-to-left layout, with the choice remembered between visits.

04

One design

The same palette, radii and component shapes as the Cambric app and download pages.

How it works

Three edits turn the template into a product site.

  1. Set the identity

    Edit index/config.json and cambric.manifest.json: name, id, version, description.

  2. Replace the copy

    Rewrite the hero, the four cards and the contact section. Keep the structure and tokens.

  3. Deploy dist/

    Run npm run build and publish the output to any static host. The included workflow can deploy to GitHub Pages.

The pieces are documented

Buttons, cards, chips, status, form fields and empty states are on one page, so a new screen starts from a known component instead of a new one.
