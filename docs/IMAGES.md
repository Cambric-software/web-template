# Image guidance

Keep visual assets intentional and lightweight:

- Prefer WebP or AVIF for photographic images.
- Keep PNG for logos, icons, and transparency.
- Export images close to their largest rendered size.
- Provide meaningful `alt` text for informative images.
- Use an empty `alt` attribute for decorative images.
- Keep filenames lowercase and use hyphens instead of spaces.
- Check the browser network panel before shipping a large asset.

The template favicon lives at `index/assets/cambric-logo.png`. Replace it during setup or product branding work and keep the same path unless the HTML and manifest references are updated together.
