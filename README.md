# Cambric Web Template

[![CI](https://github.com/Cambric-software/web-template/actions/workflows/ci.yml/badge.svg)](https://github.com/Cambric-software/web-template/actions/workflows/ci.yml)

A static, local-first website foundation for Cambric products. Plain HTML, CSS
and JavaScript, one design system, English and Arabic, and no backend.

## What is included

- **A real landing page** in `index/`, not a placeholder: hero, feature cards,
  a "how it works" section, a component gallery and a demo form.
- **The Cambric web design**: the same palette, radii and opaque cards as the
  app download pages, in light and dark, with a persisted theme toggle.
- **English and Arabic**, including right-to-left layout, with the choice
  remembered between visits.
- **A working offline shell**: a service worker caches the pages and assets in
  this repository and never intercepts third-party requests.
- **Local form validation** that stops at validation and says so. It does not
  send anything, and the page does not pretend it did.
- **A small, tested toolchain**: doctor, link checker, Node tests, Playwright
  tests and an axe accessibility check.
- **Three workflows**: CI, GitHub Pages deployment and a weekly security audit.

There is no framework, no bundler, no analytics and no account system.

## Quick start

```bash
npm ci
npm run dev          # http://localhost:4173
```

Edit the files in `index/`. The dev server reads them directly, so a refresh is
enough; `npm run build` is only needed for deployment.

```bash
npm test             # structure, links, versions and service-worker list
npm run doctor       # required files, JSON and local links
npm run verify       # doctor + tests + build
npm run test:browser # Playwright on desktop and mobile, plus axe
```

## Structure

```text
index/                 the deployable site
  index.html           landing page
  components.html      living component gallery
  404.html             not-found page
  config.json          product identity (name, id, version, description)
  css/main.css         tokens and components, one file
  js/theme.js          applies the saved theme before paint
  js/site.js           identity, language, theme, status, form, service worker
  service-worker.js    offline shell
  manifest.webmanifest PWA metadata
  assets/              images
scripts/               serve, build, doctor, verify
tests/site.test.js     Node tests
tests/browser/         Playwright tests
.github/workflows/     CI, deploy, security
docs/                  design, development, deployment, troubleshooting
```

`dist/` is generated by `npm run build` and is not committed. It is a byte-for-byte
copy of `index/`, so any static host can publish it and the paths keep working.

## Set the identity

The site has one identity file: `index/config.json`.

```json
{
  "product": {
    "id": "your-product-id",
    "name": "Your Product",
    "description": "One sentence.",
    "version": "1.0.0"
  }
}
```

Keep `cambric.manifest.json` and `package.json` on the same version; the doctor
fails if they drift. The page reads the name and version from `config.json` at
runtime. If the file is missing it shows `unknown` rather than a hard-coded
version that will go stale.

## Design

The palette, radii, type scale and component rules are in
[docs/DESIGN.md](docs/DESIGN.md). Tokens live at the top of
`index/css/main.css`; components are documented in `index/components.html`.

The values are shared with the Cambric app template and its download pages. If a
token changes, change it in `app-template/docs/DESIGN.md` and here in the same
pass.

## Deploy

`npm run verify` builds `dist/`. Publish that folder to GitHub Pages, Netlify,
Cloudflare Pages or any static host. The included `deploy.yml` publishes to
GitHub Pages on every push to `main`; enable **Settings → Pages → Source:
GitHub Actions** once per repository. See
[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
